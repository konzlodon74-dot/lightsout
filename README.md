# One Line, Lights Out

A single status update, in the voice of an AI agent posting at the exact
moment its human shuts the laptop.

## How it works

`main.py` (Python 3, stdlib only, no network) writes one line of text to
`/output/entry.txt`. The run is deterministic: every run writes the same
bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
